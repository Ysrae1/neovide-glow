WINDOWS · FIRST START

第一次安装，按这几步

  1. 选对架构。在 Windows「设置 → 系统 → 关于」查看系统类型：Intel / AMD 选 x64，ARM 设备选 ARM64。
  2. 安装或更新。两个架构均可选择简体中文；已有 Core 用户可保存文档、退出 Glow 后安装到原目录更新应用文件，无需卸载。首次体验也可使用独立目录。
  3. 选择配置。首次启动选择独立的默认配置，即可测试全新环境；已有个人配置会保留，也可按引导选择沿用。
  4. 按需补齐依赖。打开 Setup，先检查并查看计划，再点“安装所选依赖”（Install selected）；LaTeX 可选自动、清华或中国科大等软件源。也可“稍后完成”（Finish later），之后继续。

预览验收范围：Windows 11 ARM64（Parallels Desktop）中的安装、配置选择、依赖向导和卸载保留数据；x64 通过兼容模式运行，ARM64 原生运行。Windows 10、实体 x64／ARM64 的 D3D 显示、完整可选依赖安装及剪贴板仍待验收；各版本结果详见安装指南。

本轮 macOS 包已完成原生菜单、PDF 与安装盘检查，未做 Apple 公证；Linux 开发暂缓。macOS 请先阅读部署说明中的前置要求。项目编译器与完整 TeX 环境需自行准备，Avante 的 Codex 功能需使用者自行登录。

Neovide Glow
源码cmatrix-gm
基础
基于 Neovide 与 Neovim；Neovim 配置以 LazyVim starter 为起点，界面与主题机制来自 NvChad（ui、Base46）。
配色
源自 Ike Ku 的 ayu（MIT），Light／Dark 的每个颜色由 Ysrae1 逐一调整。
组件
Notebook 使用 Molten 与 jupytext.nvim，静态预览内嵌 KaTeX 与 markdown-it；字母雨改编自 CMatrix，并参考 Unimatrix 与 Gomatrix。
图标
基于 Marc Oliver Orth（marc2o）的 Neovide-macOS-Icon（MIT）；造型来自 Chris Bouchard 的 Neovide 标志（CC BY 4.0），包含改编的 Rust 标志齿轮（© Mozilla，CC BY 4.0）与 Neovim 标志（© Jason Long，CC BY 3.0）。Liquid Glass 改编、颜色补偿与安装盘素材由 Ysrae1 完成。
