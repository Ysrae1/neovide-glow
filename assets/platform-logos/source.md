# Platform logo sources

Checked 2026-10-24. These marks identify the platform; they do not imply endorsement.

- `macos.svg`: Apple silhouette extracted from the current [Apple Mac page](https://www.apple.com/mac/) global navigation SVG. The path is unchanged; the viewBox crops navigation padding and the fill uses `currentColor`. Apple and macOS are trademarks of Apple Inc. The asset is proprietary; [Apple trademark guidelines](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html) apply. This is the Apple platform mark, not a separate macOS product logo.
- `windows.svg`: Four-pane symbol extracted from the current [Microsoft Windows page](https://www.microsoft.com/en-us/windows) inline Windows brand SVG. The symbol subpaths are unchanged; the wordmark is omitted, the viewBox crops to the symbol, and the fill uses `currentColor`. The [February 2026 Windows trademark guidelines](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/mscle/documents/presentations/Windows_Trademark_Guidelines_2026.pdf) confirm the current front-facing symbol. Windows is a trademark of Microsoft Corporation. This is a proprietary trademark asset, not an open-source icon license.
- `linux.svg`: [Tux vector by Garrett LeSage, refined by IFo Hancroft](https://github.com/garrett/Tux/blob/ecd40de64250ea2b24c849e901c3297ad01e54f6/tux.svg), based on Larry Ewing's original Tux made in The GIMP. [Source license](https://github.com/garrett/Tux/blob/ecd40de64250ea2b24c849e901c3297ad01e54f6/README.md): CC0 1.0 / public domain dedication. [kernel.org FAQ](https://www.kernel.org/faq.html) confirms Tux's origin and free use with proper credit. Editor metadata and unused editor extensions were removed; the original paths, colors and internal gradients remain. This is an attributed community vector reconstruction, not an official kernel.org SVG download.

- `linux-mask.svg`: The unchanged monochrome [Linux SVG from Simple Icons](https://github.com/simple-icons/simple-icons/blob/30053a0f492fd192740ad001031b3091be060986/icons/linux.svg), pinned to commit `30053a0f492fd192740ad001031b3091be060986` (checked 2026-10-24). The `0 0 24 24` viewBox and compound path preserve transparent internal eye, beak, belly, wing and foot details for the shared animated color-field alpha mask. Simple Icons distributes its icon collection under [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/30053a0f492fd192740ad001031b3091be060986/LICENSE.md); a local copy is retained in `simple-icons-LICENSE.txt`. Its [Linux metadata](https://github.com/simple-icons/simple-icons/blob/30053a0f492fd192740ad001031b3091be060986/data/simple-icons.json) credits the Linux Foundation's Linux mark page as its source. Tux originates with Larry Ewing's artwork made using The GIMP. This is a community icon adaptation; the original full-color vector remains separately available as `linux.svg`.

All four SVG files are self-contained static SVGs with viewBox attributes, no scripts, and no external resource references. Local gradient/filter references in the full-color Tux remain internal.
